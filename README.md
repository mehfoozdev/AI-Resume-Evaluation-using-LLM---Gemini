# SmartCV Analyzer 🚀

Welcome to **SmartCV Analyzer**, an AI-powered tool to evaluate resumes against job descriptions and extract key candidate details. Built with **Google Gemini** and **LangChain**, this project uses **Generative AI** to streamline recruitment.

---

## Features ✨

- **Resume Evaluation:** Scores resumes based on job descriptions.
- **Candidate Details Extraction:** Extracts name, degree, experience, and technical skills.
- **AI-Powered Insights:** Provides actionable feedback to improve resumes.

---

## How It Works 🤖

1. Upload a **PDF resume**.
2. Enter the **job description**.
3. Get an **AI evaluation report** and candidate details.

---

## Tech Stack 💻

- **Google Gemini**: For AI-powered evaluation.
- **LangChain**: For prompt management.
- **Streamlit**: For the web interface.
- **PyMuPDF (fitz)**: For PDF text extraction.

---

## Prerequisites
- Python 3.8+
- Google API key for Gemini
